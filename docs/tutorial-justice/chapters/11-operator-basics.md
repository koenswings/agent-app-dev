# 11. Operator basics (skeleton — not yet captured)

For the school's IDEA operator, not for every teacher. Screens need operator credentials from Atlas; all wording **to confirm** against the live Console.

## O1. Operator Login
1. In the Console, click the person icon (top right). The **Operator Login** panel opens. <!-- screenshot:O1-01 -->
2. Type the operator username and password, click **Log in**. <!-- screenshot:O1-02 -->
3. Log out when done (**to confirm** where).

## O2. The Network view: Engine and disks
1. After login, open the network/disk view (**to confirm** menu name). <!-- screenshot:O2-01 -->
2. You see the IDEA box (Engine) and its disks with role badges: **app**, **backup**, **files**, **empty**. <!-- screenshot:O2-02 -->
3. Click a disk to see its apps, size and free space. <!-- screenshot:O2-03 -->

## O3. App status
1. Click an app row: status Running / Stopped / Undocked (**to confirm** labels), and **Open**. <!-- screenshot:O3-01 -->
2. Only start or stop an app when the IDEA contact asks you to (**to confirm** policy).

## O4. Command History
1. The clipboard icon shows recent Engine commands with ✓ (done) or ✗ (failed). Use it when reporting a problem. <!-- screenshot:O4-01 -->

## O5. Safely ejecting a disk
1. Open the disk, click **Eject**, read the list of what will stop, confirm. Never during a backup. <!-- screenshot:O5-01 -->

## O6. Dangerous buttons
**Erase this disk…**, **Install App**, **Make this a Files/Backup Disk**: only with the IDEA contact on the phone. <!-- screenshot:O6-01 -->
