# 9. Keeping data safe: the Backup Disk

The operator looks after backups (chapter 11). As a teacher you should know:

- A **Backup Disk** is a separate USB disk with the **backup** badge in the Console.
- It saves the **apps' data**: Kolibri (classes, learners, progress) and Nextcloud (accounts, and the files inside Nextcloud).
- It does **not** save the **School Files** folder (chapter 8).
- During a backup, the app stops for a short time and then starts again. Backups are planned outside lesson time.
- How often backups run (on request, each time the disk is plugged in, or on a schedule) is set by your IDEA contact.
- If the IDEA box breaks, the operator restores the latest backup onto a spare disk. Only the work done after the last backup is lost.
- Never unplug a disk while a backup is running.
