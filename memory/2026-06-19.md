## Key bugs found and fixed

### Browser cache (the big one)
Next.js was setting `Cache-Control: s-maxage=31536000` (1 year) on HTML routes. After every deploy, browsers served stale HTML referencing old (now 404) JS chunks. Fixed in 1.0.70 with `no-cache, no-store, must-revalidate` on all HTML routes in `next.config.ts`.

**Rule going forward:** browsers will now always fetch fresh HTML. No more "hard refresh" needed after deploys.

### P3 explainer was showing P2 numbers
The explainer for Predictor 3 was showing surplus-derived correction (P2 formula) instead of P3's T* search. Also the "X min later/earlier than standard" delta was comparing P3's result against the Standard pill's time — meaningless if the two pills had different bottle sizes. Both fixed in 1.0.67/1.0.68.

### Smoothed graph appeared flat
Graph started at `lastFeedTs` with only 40 samples. Within a 2-3h window after a recent feed, all bottles are <24h old → zero decay → flat line. Fixed by extending graph 3h before lastFeed and sampling every minute.

### Credit table bug (hardcoded 90ml cutoff)
Filter for showing exhausted bottles used a hardcoded 90ml bottle size to estimate the decay window. If bottle sizes varied, the 4ml partial bottle at 26h21m was incorrectly shown as "exhausted". Fixed: credit computed per-bottle using its actual milk volume, no hardcoded cutoff.

### Catmull-Rom spline overshoots (1.0.78)
Standard Catmull-Rom (alpha=0) uses fixed tangent scaling (÷6), causing phantom spikes when points are unevenly spaced in time. Switched to centripetal Catmull-Rom (alpha=0.5) which scales tangents by chord length — prevents overshoots mathematically.

### P3 smoothed formula — important insight
Smoothed only decays when a bottle crosses the 24h mark. Credit formula:
- age ≤ 24h: full credit (milkMl)
- age > 24h: max(0, milkMl − hourlyRate × (age − 24))
With regular feeds, approximately 1 bottle is always in the decay zone, giving continuous linear decay at exactly `hourlyRate` ml/h. The standard interval = milkPerBottle / hourlyRate = full decay time past 24h, so there's always exactly 1 bottle mid-decay as long as feeds are regular.

## Build procedure (must follow every time)

```bash
# 1. In varia/baby-milk-tracker/
npm run build                                         # compile Next.js
docker build --no-cache -t koenswings/milkwise:1.0.XX -t koenswings/milkwise:latest .
docker push koenswings/milkwise:1.0.XX
docker push koenswings/milkwise:latest

# 2. On idea02 (SSH pi@idea02.tail2d60.ts.net)
docker rmi koenswings/milkwise:latest 2>/dev/null || true   # force fresh pull
docker pull koenswings/milkwise:1.0.XX
cd /instances/milkwise-idea02-001
docker compose up -d
```

**Why --no-cache matters:** Dockerfile copies pre-compiled `.next/standalone`. Without `--no-cache`, Docker reuses old layers even after `npm run build` because file mtimes may not change across the COPY step.

**Why rmi before pull matters:** Docker won't re-pull an image if it has the same tag locally, even if the digest changed. Removing first forces a fresh pull.
