## The v3 predictor model — key facts

### Physics (6.47 kg baby, 90 ml water = 100 ml milk preferred)
- `D = 970.5 ml/day`, `λ = 40.44 ml/h`, `SI = 2h 29m`
- (Design doc examples use 6.9 kg: `D = 1035 ml`, `λ = 43.1 ml/h`, `SI = 2h 19m`)

### What we track: 24-hour rolling intake I(T)
NOT an all-time balance. The all-time model never forgets illness deficits.
The 24h model resets within 24h. Formula:

```
c_i(T) = m_i                                    if age ≤ 24h
c_i(T) = max(0, m_i - λ(age - 24))             if age > 24h
I(T) = Σ c_i(T)
```

### Equilibrium behaviour (CORRECTED — important)
- Just after each standard feed: `I = D + m₀` (e.g. 1135 ml for 6.9kg)
- Just before next standard feed: `I = D` (e.g. 1035 ml)
- NOT the old wrong values of 1035/935 ml

### Predictor A — adjusted volume at standard time
- `T_A = t_last + SI`
- `V_A = (D + m₀) - I(T_A)`
- At equilibrium: `I(T_A) = D` → `V_A = m₀` (standard bottle)
- If `V_A ≤ 0`: grey out (still above ceiling at standard time)
- If `V_A > m_cap`: cap at stomach limit (135 ml milk for 90 ml water bottle)

### Predictor B — standard volume at adjusted time
- Find `T_B` where `I(T_B) = D` (daily target exactly)
- Give standard `m₀` → intake restores to `D + m₀`
- Binary search in `[t_last, t_last + 48h]`
- Intuition: **feed when the 24h window has decayed back to the daily target**
- At equilibrium: `T_B = t_last + SI`
- Underfeed: `T_B = now` (intake already below D)
- Overfeed: `T_B > SI` (intake takes longer to decay to D)

### Stomach capacity constraint
- `S(T) = Σ max(0, m_i - λ(T - t_i))` (undigested milk)
- Cap: next bottle size up (`m_cap = 135 ml` for 90 ml water preference)
- `Δt_min = max(0, (m_last + m₀ - m_cap) / λ)`
- For standard case: `Δt_min = (100+100-135)/43.1 ≈ 1h 30m`

### Real-time energy gauge
- `p = I(now) / D × 100%`
- Updates every 60s; predictors frozen until new feed logged
- States: Ahead (>105%), On track (95-105%), Getting hungry (80-95%), Hungry (65-80%), Very hungry (<65%)

## Diagram rules for MilkWise (added 2026-06-29)

- **No text overlap**: all labels, ticks, and annotations must be checked for overlap before rendering. When in doubt, offset labels or use leader lines.
- **Bottle size indicator**: use Option 3 — bottle silhouette. Slightly smaller than the test version. V_A in blue, V_B in red. Height spans from the curve level at T_A/T_B up to the equilibrium peak D+m₀.
- **I₀ tick on y-axis**: always black (it marks the intake curve, not a reference line).
- **Horizontal blue line** at I(T_A) level across to T_A, with y-axis value in blue.
