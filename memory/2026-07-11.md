**Predictor card redesign (1.1.04–1.1.11)**

*Architecture decision (agreed with Koen):*
- **Next Feed card** = rhythm anchor: always shows T_A (standard interval) + preferred bottle, no adjustments
- **Should Take card** = corrective view: unified timeline of when each standard size should be given
- Unified constraint: `readyAt(X) = max(stomachReadyAt(X), intakeReadyAt(X))`
- Noise-cut rule: show only from largest-available-now upward; suppress superseded smaller sizes
- Overfed case: all markers in future, note shown

*Calc bugs fixed:*
- `stomachReadyAtMs`: now correctly uses preferred bottle's cap for all sizes (not the cap of the bottle being evaluated)
- Sizes where `milkMl(X) ≥ stomachCapMilk` excluded from progression (can't physically fit)
- `intakeReadyAt(X)`: binary search for when intake decays to `dailyTarget − milkMl(X)`

*Display:*
- Horizontal HTML timeline (not canvas): "now" left edge tick, dots proportionally positioned, bottle size above, clock + relative time below
- Marker clamped 4–94% to avoid label clipping at edges (bug in 1.1.10 fixed in 1.1.11)
- Green dot = available now, rose = future, teal = above preferred
