## Weight history

### Data model
- `weights.json` — `[{ id, timestamp, weightKg }]`
- `weightAtTime(t, weights, fallback)` — returns weight at time T (earliest entry if T before all records)
- `dailyTargetAtTime(t, weights, mlPerKgPerDay, fallback)` — weight × mlPerKgPerDay
- All surplus/trend calculations use weight-at-time

### API
- `GET/POST /api/weights`
- `PATCH/DELETE /api/weights/[id]`
- Settings.weightKg auto-synced to most recent weight

### UI
- **Main page:** ⚖️ Weight button → modal (weight + datetime)
- **History page:** Feeds/Weight tab selector; weight entries editable/deletable
- **Analytics:** Weight tab → stats (current, gain, rate g/week) + chart + CSV export

### Important
- `weights.json` needs `chmod 666` on idea02 data dir for new entries
- Seeded with 6.47 kg on 2026-06-09

- Y axis = **surplus** (smoothed − dailyTarget), zero line = green
