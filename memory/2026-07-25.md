# 2026-07-25 Daily Note

## Weight display bug investigation

Koen noticed the app showing "7.62 kg (est.)" while the baby was actually weighed at 7.5 kg yesterday.

### Root cause
`page.tsx` always used the WHO growth model prediction when `dateOfBirthMs + sex + weights >= 1`.
The model computes a z-channel by averaging ALL historical z-scores, then projects forward to today.
If older measurements put the baby at a higher z than yesterday's 7.5 kg, the averaged z predicted
a higher weight — even the day after a real weigh-in.

### Fix shipped — v1.1.37
- Short-circuit in `page.tsx`: if latest weight is ≤ 7 days old, use it directly (weightSource = 'manual'), skip WHO projection
- WHO projection only kicks in when gap > 7 days
- TypeScript clean, Next.js build clean, deployed on idea02
