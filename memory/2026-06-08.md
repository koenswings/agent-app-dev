## Next feed predictor — Formula S (design doc approved, deployed)

### Formula
```
surplus  = smoothedTotal − dailyTargetMl   (+ overfed, − underfed)
balance  = milkPerBottle + surplus
rawNext  = lastFeed + balance / hourlyRate × 3600000
idealNext = lastFeed + idealIntervalMs
maxCorrectionMs = idealIntervalMs × (maxCorrectionPct / 100)
adjusted = clamp(rawNext, idealNext − maxCorrectionMs, idealNext + maxCorrectionMs)
```

### Key decisions
- `milkPerBottle` in Formula S = always `waterToMilk(settings.standardBottleVolume)` — the configured standard, NOT the selector
- Bottle size selector on main page = affects Target/Status display and Standard next feed timing. Does NOT affect Adjusted calculation
- `maxCorrectionPct` default = 25% (was `maxFeedGapPct` 150%)
- Signature: `nextFeedTime(feeds, hourlyRate, smoothedTotal, dailyTargetMl, settings)`

### Equivalence proof (E3 = S)
Both formulas identical: `balance_E3 = milkPerBottle + (totalMilk24h − hourlyRate×24) = milkPerBottle + surplus`
Verified empirically: diff = 0.0000min.
