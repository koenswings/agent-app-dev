### Water→formula conversion (IMPORTANT)
- Logged volumes are in **water ml** (what goes into the bottle)
- The 150 ml/kg/day target is in **prepared formula ml** (after mixing powder + water)
- Conversion is **not a constant ratio** — varies by bottle size
- Lookup table (7 data points), linear interpolation between them:

| Water ml | Formula ml |
|----------|------------|
| 30 | 35 |
| 60 | 70 |
| 90 | 100 |
| 120 | 135 |
| 150 | 170 |
| 180 | 200 |
| 210 | 240 |

- Function: `waterToMilk(waterMl)` in `calculations.ts` (shared core)
- `milkPerBottle` = `waterToMilk(settings.standardBottleVolume)` in `DerivedSettings`

### Next feed predictor — Option D (recovery-aware)
Design doc: `design/milkwise/next-feed-predictor-design.md`

Logic:
- Inside green zone (±yellowThresholdPct%): use ideal interval from last bottle volume
- Outside green zone: spread correction over `recoveryWindowHours` (default 24h)
  - `feedsInWindow = recoveryWindowHours / idealIntervalHours`
  - `correctionPerFeed = surplusMl / feedsInWindow`
  - `correctionHours = correctionPerFeed / hourlyRate`
  - Capped at ±1h max correction per feed
- Always capped at `maxFeedGapHours` (default 4h)
- Returns `{ timestamp, correctionHours, correctionDirection }` — dashboard shows indicator

New settings fields: `recoveryWindowHours` (default 24), `maxFeedGapHours` (default 4)
