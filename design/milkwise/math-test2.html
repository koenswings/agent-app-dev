§2.2   Energy Model

Prepared milk is used as the direct proxy for caloric energy: 1 ml of prepared milk = 1 unit of energy. The baby's daily nutritional need and the resulting hourly drain rate are:

D = w · r λ = D24 w = baby weight (kg),   r=150 ml/kg/day (default),   λ = hourly drain rate (ml/h).   Example: w=6.9 kg → D=1035 ml, λ=43.1 ml/h.

If the parent feeds one standard bottle of m0 ml of prepared milk every SI hours, intake stays in equilibrium. The standard interval is the time for that bottle to be fully spent at rate λ:

SI = m0 λ 90 ml water → m0=100 ml milk, λ=43.1 ml/h → SI≈2h 19m

§4.1   The Intake Function

Rather than tracking an all-time energy balance, the app tracks the total milk received in a rolling 24-hour window. The credit contributed by bottle i (volume mi, given at time ti) evaluated at time T is:

ci (T) = mi if T−ti≤24 h max 0 mi − λ T−ti−24 if T−ti>24 h

The smoothed 24-hour intake at time T is then the sum over all feeds logged before T:

I(T) = ∑ i=1 n ci (T)

The decay rate past 24 h is exactly λ — the same rate at which the baby burns energy. This is not arbitrary: a bottle's contribution to the window diminishes at the same speed as its nutritional value is consumed. In steady-state feeding, I(T) oscillates between D (just before each feed) and D+m0 (just after).

§5.1   Predictor A — Adjusted Volume at Standard Time

Predictor A answers: if I feed at the standard time, how much should I give? It computes the volume that restores intake to the equilibrium peak D+m0:

TA = tlast + SI VA = D+m0 − I(TA) At equilibrium I(TA)=D, so VA=m0 — the standard bottle.

The parent is shown VA converted to water ml and decides which bottle size to use. If VA≤0 the baby is still overfed at the standard time — Predictor A is greyed out. If VA exceeds the stomach capacity cap it is clamped (see §6).

§5.2   Predictor B — Standard Volume at Adjusted Time

Predictor B answers: when should I give my preferred standard bottle? It finds the time TB at which I(T) has decayed back to D, so that adding m0 restores intake to D+m0:

I(TB) = D Feed when the 24-hour intake returns to the daily target.

TB is found by binary search on [tlast,tlast+Tmax]. At equilibrium TB=tlast+SI. With a deficit, TB<tlast+SI; with a surplus, TB>tlast+SI.

§6   Stomach Capacity Constraint

The total undigested milk in the stomach at time T is modelled as the sum of unmetabolised portions of all recent feeds:

S(T) = ∑ i=1 n max 0 mi − λ T−ti

The constraint is S(TB)+m0≤mcap, where mcap is one standard bottle size above the preferred size. Assuming only the most recent feed is still undigested, this gives a minimum waiting time before the next feed:

Δtmin = max 0 mlast + m0 − mcap λ Example: mlast=m0=100 ml, mcap=135 ml, λ=43.1 ml/h → Δtmin = 100+100−13543.1 ≈ 1h 30m

If Predictor B's TB falls before tlast+Δtmin, it is clamped upward with a note: "Stomach not ready — baby is underfed but needs time to digest."
