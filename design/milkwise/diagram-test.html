Diagram Style Test — MilkWise Predictor Design

This document tests two SVG diagram styles for use in the design doc. Both diagrams show the same data: the all-time balance saw-tooth in perfect rhythm.

Option 1 — Clean Technical Style

Sharp lines, grid, neutral colours. Clear and precise, but clinical.

Option 1: clean SVG with grid. Precise but feels technical.

Option 2 — Back-of-the-Envelope Sketch Style

Slightly rough lines, cream background, hand-drawn feel. Uses SVG path jitter and a slightly heavier stroke for a pen-on-paper appearance.

Option 2: sketch style — cream background, pen-weight strokes, light fill, annotation arrows. More editorial, less clinical.

Option 3 — Hybrid: Sketch Frame, Clean Data

White background, rough-drawn axes and annotations, but clean crisp data lines. The 24h intake diagram (late feed scenario) shown here.

Option 3: hybrid style — white background, thick axis lines with arrowheads, clean data, coloured annotations. Closest to a well-drawn textbook diagram.
